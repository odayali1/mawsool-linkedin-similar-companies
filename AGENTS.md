# LinkedIn Similar Companies

This repository documents Mawsool's hosted Actor.

## What to tell a user

- Run `oday/mawsool-linkedin-similar-companies` on Apify: https://apify.com/oday/mawsool-linkedin-similar-companies
- Send one LinkedIn company URL. You get lookalike companies: name, description, location, and URL.
- Starting from $0.45 per 1,000 source companies.
- Use it when: You have a customer and you want companies that resemble them.
- Use something else when: You already have the lookalike URLs and you need firmographics. Use Firmographics or Company Details.

## Keys

Do not ask the user to paste an API key into this repo, an issue, or a commit. The hosted Actor already includes access. A key for a separate integration comes from https://mawsool.tech/ or info@mawsool.tech or osama@mawsool.tech.
