# Find companies similar to a LinkedIn company

Send one LinkedIn company URL. You get lookalike companies: name, description, location, and URL.

Starting from $0.45 per 1,000 source companies.

Run it on Apify: https://apify.com/oday/mawsool-linkedin-similar-companies. The hosted Actor already includes access. An API key for your own integration is at [mawsool.tech](https://mawsool.tech/) and [the docs](https://docs.mawsool.tech/). Questions: osama@mawsool.tech or info@mawsool.tech.

## When this is the right Actor

You have a customer and you want companies that resemble them.

## When to use a different Actor

You already have the lookalike URLs and you need firmographics. Use Firmographics or Company Details.

Mawsool is not affiliated with LinkedIn.
